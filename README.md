# مشاكيك الحوار

Next.js App Router, TypeScript, static export. العربية RTL، أربع صفحات، صور WebP محلية، خط Tajawal محلي، بيانات منظمة، وإجراءات اتصال واتجاهات.

Development: `npm ci` then `npm run dev`.
Build: `npm run build` → `out/`.
Read `LAUNCH-REQUIREMENTS.md` before public launch.
Menu data: `data/menu.json`. Restaurant details: `data/restaurant.json`.

Prices remain null until verified. No payment flow, fabricated reviews, sales rankings, or invented family meals are included.
